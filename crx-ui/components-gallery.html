5 · Animation primitives

.t-text-swap · .t-copy-swap · .t-panel-slide — shared is-exit / is-enter-start state machine

bookmarks
This panel expands with grid-template-rows: 0fr → 1fr plus a translateY + blur + opacity slide.
JS (the exit/enter pattern)
// exit
el.classList.add('t-text-swap'); el.classList.remove('is-enter-start'); el.classList.add('is-exit');
setTimeout(() => {
  el.textContent = nextText;                       // content swaps here
  el.classList.remove('is-exit'); el.classList.add('is-enter-start');
  void el.offsetHeight;                            // force reflow
  el.classList.remove('is-enter-start');           // play enter transition
}, 200);
